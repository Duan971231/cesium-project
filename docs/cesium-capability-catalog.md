# 寰图 · Cesium 能力展厅规划

**版本** v0.1　**日期** 2026-11-25　**适用项目** cesium-example

## 1. 产品目标

将现有三维地球工作台扩展为面向客户的 WebGIS 能力展厅。客户可以按功能试用单项效果，也可以按行业场景查看多项能力如何协同。展厅兼作项目的功能台账，每完成一项，就补上演示入口、数据来源和验收结果。

| 入口       | 面向客户的用途                 | 内容                                                         |
| ---------- | ------------------------------ | ------------------------------------------------------------ |
| 能力目录   | 快速确认能做什么，点击即可试用 | 基础、进阶、高级功能卡片，每张卡片有预览、操作说明和演示入口 |
| 场景案例   | 了解如何用于实际业务           | 城市与园区、气象与环境、山区巡检三个可操作案例               |
| 自由工作台 | 自由叠加图层，尝试组合效果     | 沿用现有 /globe，复用各功能模块和独立配置面板                |

每个演示默认加载一份示例数据，自动定位到合适视角，打开相关面板，提供一键恢复。优先做能通过独立链接打开的演示，客户可直接进入某个案例。

## 2. 功能台账

**基础**覆盖浏览、图层和常用操作。**进阶**覆盖多源业务数据、模型和时序交互。**高级**覆盖自定义渲染、空间分析或工程交付能力。

**已有**表示当前仓库已有模块和界面入口。**部分已有**表示已有可复用能力，卡片目标仍需补齐。**待开发**表示本次盘点未发现对应入口。演示实际通过后，可将状态更新为 **可演示**，并在该行补链接。

### 基础能力

| 编号 | 功能                 | 演示与验收                                                 | 当前状态                             |
| ---- | -------------------- | ---------------------------------------------------------- | ------------------------------------ |
| B01  | 数字地球与视图切换   | 同一区域切换 2D、2.5D、3D，操作平移、旋转、缩放和视角复位  | 已有                                 |
| B02  | 底图与图层管理       | 切换电子地图和卫星影像，演示图层显隐、透明度和顺序         | 部分已有，待补叠加管理               |
| B03  | 地形高程             | 在固定山区视角开关地形，对比平面和起伏效果                 | 已有，默认高程地址依赖本地服务       |
| B04  | 地点定位与视角书签   | 输入经纬度定位，在收藏视角之间切换                         | 部分已有相机坐标读数，待补定位和书签 |
| B05  | 地图标绘             | 绘制点、线、面和文字，拖动控制点，改样式，删除后可继续绘制 | 已有，可扩展保存与导入导出           |
| B06  | 网页区域截图         | 框选带地球和界面面板的区域，下载 PNG                       | 已有                                 |
| B07  | 距离、面积和高差测量 | 使用固定样例计算距离、面积和高差，显示单位及测量口径       | 待开发                               |

### 进阶能力

| 编号 | 功能                          | 演示与验收                                                       | 当前状态                               |
| ---- | ----------------------------- | ---------------------------------------------------------------- | -------------------------------------- |
| M01  | 3D Tiles 实景、建筑白模和点云 | 从全景飞近样区，切换数据类型，点选带元数据的建筑或要素           | 待开发，首版可从一个实景或白模样区起步 |
| M02  | 矢量图层与属性联动            | 加载点位、路线和区域，按属性筛选，列表定位地图，地图点选反查详情 | 待开发                                 |
| M03  | 专题渲染                      | 切换点聚合、热力图与区域分级设色，显示图例，演示筛选后的变化     | 待开发                                 |
| M04  | glTF 模型与场景布置           | 放置一个设备模型，调整位置、朝向和比例，点击查看设备信息         | 待开发                                 |
| M05  | 轨迹回放与相机跟随            | 播放、暂停、倍速、拖动时间轴，查看对象位置、姿态和历史轨迹       | 待开发，首版使用本地轨迹               |
| M06  | 影像卷帘与时序对比            | 拖动分割线对比同一区域的两期影像，标明日期和覆盖范围             | 待开发，需要成对素材                   |
| M07  | 实时位置与状态接入            | 接入一组车辆或设备位置与状态流，显示更新时间和连接状态           | 待开发，需要数据服务                   |

### 高级能力

| 编号 | 功能               | 演示与验收                                                                      | 当前状态                                                     |
| ---- | ------------------ | ------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| A01  | GPU 风场           | 调整粒子密度和速度，查看风速色标，拖动地球观察粒子运动，支持 GPU 与 Canvas 切换 | 已有，使用本地 GFS 近地面风场快照                            |
| A02  | 体积云与环境渲染   | 在 3D 中从云下飞到云上，切换云量、亮度和画质预设，查看地形遮挡效果              | 已有程序生成云和独立面板，2D 和 2.5D 暂停渲染                |
| A03  | 地形高程剖面       | 沿路线采样地形，显示距离和高程曲线，鼠标移入曲线时定位地图                      | 待开发，优先与巡检回放组合                                   |
| A04  | 通视与可视域       | 在预设观测点展示地形或建筑遮挡，呈现结果时注明数据精度、采样方式和观测高度      | 待开发，需要分析实现及数据验证                               |
| A05  | 三维剖切与地下空间 | 移动剖切面查看模型内部，按楼层显示建筑，叠加地下管线并查看属性                  | 待开发，需要分层模型或管线数据                               |
| A06  | 大数据量渲染       | 逐档增加点位或标绘，记录首次加载耗时、帧率和帧间隔，注明设备与分辨率            | 部分已有，具备 Primitive 标绘和 GPU 风场，待做公开演示及实测 |
| A07  | 内网与私有部署     | 按目标环境用内网服务加载底图、地形、模型和样例数据，验证所需资源可用            | 部分已有本地资源使用方式，待整理部署方案并验收               |

现有入口位于项目的 src/views/GlobeView.vue。地图控制、标绘、截图、风场和体积云分别在 src/modules 下维护。风场与体积云的实现说明可见项目中的 docs/wind-rendering.md 和 docs/volumetric-clouds.md。本表状态基于仓库盘点。

## 3. 客户场景案例

| 案例           | 建议演示顺序                                                         | 首版所需数据与能力                                                 |
| -------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 城市与园区实景 | 飞入园区 → 在实景和白模之间切换 → 点击建筑 → 筛选设施 → 对比两期影像 | 小范围 3D Tiles 样区、带属性的园区点位。卷帘数据齐备后加入最后一步 |
| 气象与环境     | 打开全球风场 → 定位一个区域 → 查看风速色标 → 打开体积云 → 切换画质   | 项目已有风场快照和云层模块。卡片标明快照时间与云层生成方式         |
| 山区巡检回放   | 定位巡检路线 → 播放轨迹 → 跟随巡检对象 → 查看地形剖面 → 标注并截图   | 本地轨迹、地形数据、回放和剖面模块，复用已有标绘与截图             |

## 4. 建设顺序

### 第一批 · 把已有能力做成演示

- [ ] 建立能力目录，接入数字地球、地形、标绘、截图、风场和体积云演示。
- [ ] 为每个演示设置初始化视角、默认参数和恢复操作。
- [ ] 为对外演示准备可访问的底图、高程和静态数据，核对来源、署名与可用范围。
- [ ] 完成气象与环境案例，梳理客户可以直接操作的步骤。

### 第二批 · 补齐关键数据和业务交互

- [ ] 接入一个 3D Tiles 样区，完成加载、定位、点选和属性展示。
- [ ] 完成距离、面积、高差测量和独立测量面板。
- [ ] 加入本地轨迹回放、时间轴和相机跟随。
- [ ] 实现路线高程剖面联动，完成山区巡检案例。
- [ ] 加入属性筛选与图层切换，完成城市与园区案例的首版。

### 第三批 · 扩展高级分析和交付能力

- [ ] 按场景需要选做通视、可视域、模型剖切、地下空间和实时数据接入。
- [ ] 准备台阶式数据量，按统一机器、相机操作和分辨率记录性能。
- [ ] 选择一个目标内网环境，验证示例数据和静态资源的访问。

**推荐优先级** 先把已有的风场、体积云做成能直接打开的演示，再集中补三维实景、轨迹回放和高程剖面。这三项新能力可以支撑两套完整的业务案例。

## 5. 新功能记录模板

| 字段             | 记录内容                                             |
| ---------------- | ---------------------------------------------------- |
| 编号、名称、等级 | 沿用上表编号，新增能力按所属等级递增                 |
| 客户价值         | 一句话描述客户能看到或完成什么                       |
| 状态、优先级     | 待开发、开发中、待验收、可演示，优先级由当前迭代确定 |
| 演示入口         | 填页面地址、默认视角和演示步骤                       |
| 数据与运行条件   | 填样例文件、来源、适用范围、外部服务与设备要求       |
| 验收与结果       | 写一条可复现操作，补预期画面、实际结果和验证日期     |
| 配置与限制       | 记录关键参数、支持的场景模式和已知边界               |

### 通用验收清单

- [ ] 从卡片直达演示，示例数据加载完成后显示预期画面。
- [ ] 默认配置下可以复现演示步骤，修改参数后可以恢复。
- [ ] 切换基准视图时交互符合该能力的支持范围，需要限制的模式有明确提示。
- [ ] 加载失败、缺少数据或设备能力不足时有可理解的状态提示。
- [ ] 演示数据来源、日期和类型有标注，涉及测量、分析和性能的描述可追溯到验收记录。
